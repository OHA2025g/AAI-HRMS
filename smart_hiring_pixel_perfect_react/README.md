# AAI-HRMS Smart Hiring Dashboard — Pixel-Perfect React Files

## Run
npm install
npm run dev

## Build
npm run build

## Structure
- src/App.jsx: React shell with tab switching
- src/styles.css: shell CSS
- src/data/*.js: original tab HTML preserved for pixel-perfect rendering
- public/smart_hiring_dashboard_pixel_perfect.html: standalone original HTML copy
- vanilla/: plain HTML/CSS/JS starter
